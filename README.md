# 나만의 가계부 배포 가이드

이 프로젝트는 React와 Vite로 만들어졌습니다. GitHub를 통해 무료 호스팅 서비스(Vercel, Netlify 등)에 쉽게 배포할 수 있습니다.

## 무료 배포 방법 (Vercel 권장)
1. 이 소스 코드를 본인의 GitHub 저장소(Repository)에 업로드합니다.
2. [Vercel](https://vercel.com/) 사이트에 접속하여 GitHub 계정으로 로그인합니다.
3. 'Add New...' -> 'Project'를 클릭합니다.
4. 방금 업로드한 GitHub 저장소를 선택(Import)합니다.
5. Framework Preset이 'Vite'로 자동 선택되어 있는지 확인 후 'Deploy' 버튼을 누릅니다.
6. 1~2분 뒤 배포가 완료되며, 평생 무료로 접속할 수 있는 나만의 고유 도메인 주소가 발급됩니다.
